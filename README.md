# HNA-Blueprint

Contents of the project


### generate_hna_excel


This folder contains the files and code to produce `HNA_databooks` per subdivision.

You'd need the subdivision GEOCODE to get the desired file.

Your R knowledge should be Intermediate to run this code.

In the script named `excel_generator.R`, change the `community_list()` vector with the subdivision(s) code(s) you wish to generate. Then, run all the script.

### generate_hna_word

This folder contains the files and code to produce `Housing Needs Assessment` reports at municipal level.

You will need the `HNA_databook` corresponding the desired subdivision to generate the report, and the `HNA Municipal Template`, provided in this repository.

Your Python knowledge should be Intermediate to run this code.

Please, refer to the `SETUP.md` file to get the detailed instructions to set up the `Virtual Environment`.
